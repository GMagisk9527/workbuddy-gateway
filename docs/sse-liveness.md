# SSE 静默保活、首增量期限与事件分帧

三个模型入口及其聚合出口共用事件读取器和首增量期限；流式出口另有静默保活。
所有验证使用合成数据和本地 HTTP 服务，不发送额外模型请求。

## 静默期保活

`upstream.streamKeepaliveSeconds` 默认 15 秒，省略或非正数沿用默认。
整个流中若距上次成功写入已达到该间隔，发送 `: keepalive` SSE 注释。
模型数据、协议前置事件和上游已有注释都会更新下游写入时间，避免正常输出时重复补心跳。
首个数据之后的思考或工具间隔也能保活。

心跳与数据共用写锁和已有写截止时间；写入/刷新失败仍关闭上游并取消请求，
费用按已观测用量结算。读取结束并决定不再重放后停止心跳，再发送成功或失败终态，
不会在 `[DONE]`、`message_stop` 或 `response.completed` 后追加注释。
等待允许的重放及其结算时仍保留心跳，客户端写失败会阻止后续发送。

心跳不计入 token、TTFT 或费用，也不改变已收到模型数据后的重放限制。
它能减少因静默造成的代理断开，不能恢复已经中断的 SSE。

## 首个有效增量期限

```json
"upstream": {
  "firstTokenTimeoutSeconds": 300
}
```

**旧配置省略此字段也会启用 300 秒期限；显式设为 0 可关闭。**
范围 0～3600 秒，支持热加载；同一逻辑请求使用进入时的配置快照。

- 从首次收到上游成功响应头开始计时，覆盖流式和聚合请求。之前的请求读入、准入、
  选号、建连与响应头等待仍使用各自现有规则。
- 正文、拒答、推理和工具增量沿用 TTFT v2 的识别规则。收到首个有效增量即停止此
  一次性期限，持续输出的长回复不会因它被截断。合法空回复正常结束也会停止计时。
- 注释心跳、角色声明、usage、`response.created` 等控制信息不会完成首增量等待。
  下游补发心跳也不会延长它。
- 换号、首字节重放、退避与重放前结算沿用同一期限，不会在第二次调用重新计时。
  到期取消逻辑请求内的上游操作，不再发送额外模型尝试。

未建立下游流时返回 504；流式出口使用已有错误事件格式，错误码为
`upstream_first_token_timeout`。不会追加成功终态，也不会将网关内部期限误计为
客户端主动取消。已收到的实测费用保留；没有 usage 的已发出成功响应保持未知费用，
未发送或已明确拒绝的重放不会因为外层 SSE 的 HTTP 200 多记一次未知费用。
同步账本结算仍需完成，期限不会强制中断 WAL 写入。

这项期限与原有 `upstream.idleTimeoutSeconds` 独立。后者仍按上游原始字节判断空闲，
本改动没有为首增量之后的整条生成设置总时长限制。

## 事件分帧和兼容边界

标准 SSE 按空行结束事件，支持 LF、CRLF、独立 CR 和跨网络读取的分隔符。
同一事件的多条 `data:` 按规范用换行拼接；只剥离流开头的 UTF-8 BOM。
注释保持注释，event/id/retry 等元数据不包装为模型 JSON。

每个完整事件连同元数据最多 4 MiB，多条小 `data:` 也共享此上限。
常见单 data 事件直接引用读取缓冲，多行事件使用可复用的拼接缓冲。
整段 JSON 校验、业务拒绝识别、工具参数及数字精度沿用原路径。
`[DONE]` 结束后立即停止，不继续等 HTTP 连接关闭。

保留裸 JSON 行、裸 `[DONE]` 和重复 `data:` 前缀的既有兼容。
标准 `data:` 事件需要空行结束：EOF 前没有结束空行的事件不会交付，
即使其中 JSON 本身完整，也按不完整响应失败；仅用单换行分隔多个 JSON 的非标准
SSE 来源需要补齐事件分隔符。回归夹具中的标准 SSE 已同步使用完整分隔符，
原有关闭、结算与工具合并断言保留。

重放会识别每次新上游流的 BOM；有效数据到达后不会因为 BOM 或 CR 分隔而误判为
“尚未交付”，从而错误重复请求。

事件与心跳语义依据 [WHATWG SSE 规范](https://html.spec.whatwg.org/multipage/server-sent-events.html)。

## 验证

回归覆盖三协议、流式/聚合、快慢路径、已知/零/未知费用、静默后恢复保活、
首增量后的长暂停、配置快照与关闭、重放退避/结算期间到期，以及真实 HTTP/1.1
和 HTTP/2 的上游取消。分帧另覆盖 BOM 分段、各种换行边界、多行事件总量、
末尾不完整事件、工具参数大整数和终态后不再读取。

```sh
go test -run 'Test(FirstToken|FirstIncrement|StreamHeartbeat|UpstreamSSE|MultilineSSE)' -count=1
go test -run '^$' -fuzz '^FuzzUpstreamSSEFragmentation$' -fuzztime=10s -parallel=2
```
